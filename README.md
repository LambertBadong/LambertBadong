## How I work

- **Measure it.** Time saved is timed on real work, and estimates are labelled as estimates.
- **Make it safe before making it fast.** Tools that touch production files archive first, check their own results and refuse when unsure.
- **Keep AI accountable.** Agents work from written rules, log what they did, and say plainly what they did not verify.
